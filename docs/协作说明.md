# 广理职小鱼 · 协作说明（每个人都要看）

## 1. 我们在做什么

一个校园版"闲鱼"：同学之间买卖闲置物品。

```
C# 客户端（Windows 窗口程序）  ⇄  TCP 长连接 + JSON  ⇄  C 服务器（Linux / Windows）  →  SQLite 数据库
```

- **客户端**：C# + WPF，负责所有界面
- **服务器**：C 语言，负责存数据、处理业务、给在线用户推送消息
- 两边怎么说话写在《协议文档》里，**这是全组的合同，谁都不能私自改**

## 4. 装环境

1. 安装 **Visual Studio 2022**（社区版免费），已经装了的话打开 Visual Studio Installer 点"更新"到最新版。
2. 在 Visual Studio Installer 里勾选工作负载：
   - C 组员（C、D）：**使用 C++ 的桌面开发**
   - C# 组员（A、B）：**.NET 桌面开发**
3. 打开项目：
   - 服务器：VS → 文件 → 打开 → **文件夹**，选 `server` 文件夹，等底部输出窗口显示"CMake 生成完毕"
   - 客户端：双击 `client/XiaoYu.sln`

具体怎么运行，看自己的任务说明。

## 5. 规则（很重要）

1. **只改自己文件夹里的文件**。别人的文件、公共文件（头文件、`core/`、`Services/`、`Styles/`、`Shell/`、`XiaoYu.Core/`）一律不动。
2. **不要改协议**，不要改函数名和参数。觉得不合理，在群里提出来。
3. 需要公共部分加东西（比如一个新样式、一个新的公共函数），**在群里提出来**，不要自己加。
4. 交之前**必须能编译通过**。编译不过的代码等于没交。

## 6. 用 AI 写代码的正确姿势

可以用 AI，但答辩时老师会问你自己的代码，**你必须能讲清楚每一段在干什么**。

推荐这样用：

1. 把《协议文档》里自己那一节、自己的任务说明、要改的那个文件，一起发给 AI。
2. 一次只让它写**一个函数**，不要一口气写完整个文件。
3. 写完马上编译运行、跑测试，不对就把错误信息贴给 AI。
4. **每个函数都让 AI 逐行解释一遍**，看不懂的地方追问到懂为止。
5. 别让 AI 改你负责范围以外的文件。它说"需要修改 xxx.h"时，先在群里提出来。

## 7. 怎么交

1. 关掉 Visual Studio。
2. 删掉这些自动生成的文件夹（很大，而且没用）：
   - 服务器：`server/out`、`server/build`、`server/.vs`
   - 客户端：`client/.vs`，以及每个项目下的 `bin`、`obj`
3. 把**整个项目文件夹**压缩成 zip，文件名：`组员X-姓名-日期.zip`，比如 `组员C-张三-1111.zip`。
4. 提交压缩包。

提交后，你的代码会放进 Git 仓库，提交记录上写你的名字。
