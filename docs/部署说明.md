# 部署说明

## 线上部署一览

全部放在一台云服务器（Ubuntu，ARM64）上：

| 部分 | 地址 | 怎么装 | systemd 服务 |
|---|---|---|---|
| 服务器（C） | 本机 `127.0.0.1:9527` | `deploy/install-linux.sh` | `xiaoyu` |
| TLS 加密 | `server.aaalez.com:443`（直连，nginx 解密后转给 9527） | `deploy/install-tls.sh` | `nginx` |
| 审核后台（ASP.NET Core 网页） | `https://admin.aaalez.com` → 本机 `127.0.0.1:5280` | `deploy/install-admin.sh` | `xiaoyu-admin` |
| 门户网站 + 客户端下载 | `https://xiaoyu.aaalez.com` → 本机 `127.0.0.1:8088`（nginx） | `deploy/install-portal.sh` | `nginx` |
| Cloudflare 隧道 | 把上面两个网址转到本机端口 | 见下文 | `cloudflared-xiaoyu` |

为什么用 443 端口：云服务器的安全组只开放了 22/80/443，用 443 不用再去改云平台的设置。
网页（后台、门户）不能再占 443，所以通过 Cloudflare 隧道访问：服务器主动连到 Cloudflare，不需要开放任何端口，HTTPS 证书也由 Cloudflare 提供。

## 1. 服务器

```bash
git clone <仓库地址> && cd xiaoyu
sudo apt install build-essential cmake libcurl4-openssl-dev
sudo bash deploy/install-linux.sh            # 默认只听本机 127.0.0.1:9527
```
- 程序用专用用户 `xiaoyu` 运行，不是 root（如果直接监听 443 这类小于 1024 的端口，脚本会只授予"绑定低端口"这一项权限）
- 配置文件 `/etc/xiaoyu/server.conf`（已存在就不覆盖），数据在 `/var/lib/xiaoyu`
- 密钥放在 `/etc/xiaoyu/secrets.env`（只有 root 能读，**不进代码仓库**），例如：
  ```
  OPENROUTER_API_KEY=sk-or-...
  XIAOYU_SMTP_PASS=邮箱的应用专用密码
  ```
- 设置管理员（能登录审核后台）：`sudo -u xiaoyu /opt/xiaoyu/bin/xiaoyu_server /etc/xiaoyu/server.conf --set-admin 用户名`

### 配置项（`server.conf`）

| 项 | 默认 | 含义 |
|---|---|---|
| `bind` | `0.0.0.0`（脚本生成的是 `127.0.0.1`） | 监听地址 |
| `port` | `9527` | 端口 |
| `db_path` | `data/xiaoyu.db` | 数据库文件 |
| `data_dir` | `data` | 图片等数据目录 |
| `log_file` | `data/server.log`（脚本生成的是空） | 日志文件，空 = 输出到屏幕 / systemd 日志 |
| `max_frame_mb` | `8` | 单条消息最大多少 MB |
| `idle_timeout` | `120` | 多少秒收不到客户端消息就断开 |
| `require_email` | `1` | 注册必须验证邮箱 |
| `smtp_url` / `smtp_user` / `smtp_pass_env` | 空 / 空 / `XIAOYU_SMTP_PASS` | 发验证码邮件。不配 `smtp_url` = 开发模式（验证码写进日志，并在回复里带回 `dev_code`） |
| `jev_model` | `jev-1.14` | AI 审核用的模型 |
| `jev_source` | 无 | AI 调用源："地址 密钥所在的环境变量"，可以写多行，按顺序试。不配 = 不开 AI 审核（商品直接上架，举报全部转人工） |

## 1.5 TLS 加密

```bash
sudo apt install nginx libnginx-mod-stream certbot
bash deploy/install-tls.sh server.aaalez.com
```
脚本会：用 certbot 通过 80 端口申请 Let's Encrypt 免费证书（到期前自动续期）→ 把服务器改成只听 `127.0.0.1:9527` → 配置 nginx 的 stream 模块在 443 端口做 TLS 并转发 → 用 Python 做一次 TLS 握手和 `sys.ping` 检查。
- 客户端用 `SslStream` 连接，按 Windows 自带的证书信任链校验证书，证书不对就拒绝连接
- nginx 还限制了同一个 IP 最多 30 条连接；连接日志在 `/var/log/nginx/xiaoyu-stream.log`
- 服务器日志里所有连接都显示为 `127.0.0.1`（因为是 nginx 转过来的），要看真实 IP 查上面的 nginx 日志

## 2. 审核后台

```bash
bash deploy/install-admin.sh          # 普通用户运行（需要 .NET 8 SDK），安装那一步会自动 sudo
```
- 发布成自带 .NET 运行时的程序，装到 `/opt/xiaoyu-admin`；只监听 `127.0.0.1:5280`，自动连本机服务器（端口从 `server.conf` 读）
- 每次启动用一个临时的无权限用户运行，它不碰数据库，所有操作都是通过 `admin.*` 命令交给服务器
- 登录 Cookie 默认只走 HTTPS；要在本机用 http 调试，加 `XIAOYU_ADMIN_HTTP=1`
- 本机调试：`cd client/XiaoYu.Admin && XiaoYu__ServerPort=9527 dotnet run`，然后打开 http://127.0.0.1:5280

## 3. 客户端 exe 和门户网站

**编译线上版 exe**（在 Windows 上，装了 .NET 8 SDK）：
```powershell
dotnet publish client\XiaoYu.App\XiaoYu.App.csproj -c Release -r win-x64 -p:Online=true -o out
```
得到一个约 64 MB 的 `out\XiaoYu.exe`：自带 .NET 运行时，不用安装；旁边没有 `appsettings.json` 时默认用 TLS 连 `server.aaalez.com:443`。
平时开发用的 Debug 版仍然默认是假数据模式。

**安装门户网站**（在服务器上）：
```bash
bash deploy/install-portal.sh 路径/XiaoYu.exe 1.0.0
```
网页文件来自仓库的 `portal/`，exe 放到 `download/` 下，页面上的版本号、大小、SHA-256 校验值在安装时自动填好。

exe 没有代码签名，下载和第一次运行时 Windows 会提示"已保护你的电脑"，点"更多信息 → 仍要运行"即可（门户页上写了）。开启了"智能应用控制"的 Windows 11 会直接阻止，只能换电脑。

## 4. 域名和 Cloudflare 隧道

域名 `aaalez.com` 托管在 Cloudflare：
- `server.aaalez.com`：A 记录 → 服务器 IP，**灰云**（不经过 Cloudflare 代理，因为客户端用的是自己的 TCP 协议，不是 HTTP）
- `admin.aaalez.com`、`xiaoyu.aaalez.com`：指向一条 Cloudflare 隧道（由 Cloudflare 远程管理配置），隧道把它们分别转到本机 `127.0.0.1:5280` 和 `127.0.0.1:8088`
- 隧道程序 `cloudflared` 装成服务 `cloudflared-xiaoyu`，令牌放在 `/etc/cloudflared/xiaoyu.env`（只有 root 能读）

## 5. 本机开发 / 局域网

```bash
sudo bash deploy/install-linux.sh                         # 只允许本机连 127.0.0.1:9527
XIAOYU_BIND=0.0.0.0 sudo -E bash deploy/install-linux.sh  # 让局域网的电脑也能连
```
- 记得放行防火墙端口（Windows 防火墙 / 云服务器安全组 / `ufw allow 9527`）
- 客户端的 `appsettings.json` 里把 `UseFakeApi` 改成 `false`，`Host` / `Port` 改成服务器的地址；连有 TLS 的服务器时把 `UseTls` 改成 `true`
- 在 Windows 的 WSL 里也能这样装；WSL 空闲后会自己关掉，演示前开一个 WSL 终端不关即可

## 日常操作

| 要做什么 | 命令 |
|---|---|
| 看状态 / 日志 | `systemctl status xiaoyu xiaoyu-admin`、`journalctl -u xiaoyu -f` |
| 改配置 | 编辑 `/etc/xiaoyu/server.conf`，然后 `sudo systemctl restart xiaoyu` |
| 更新服务器 | 拉新代码后重新运行 `install-linux.sh`（配置和数据不会被覆盖） |
| 更新后台 / 门户 | 重新运行 `install-admin.sh` / `install-portal.sh` |
| 备份 | 复制 `/var/lib/xiaoyu`（数据库 `xiaoyu.db` 和图片都在里面） |
| 灌演示数据 | `dotnet run --project client/tools/Seed -- 127.0.0.1 9527`（服务器要在开发模式，即没配 SMTP） |
| 卸载服务器 | `sudo systemctl disable --now xiaoyu; sudo rm -r /opt/xiaoyu /etc/systemd/system/xiaoyu.service` |
